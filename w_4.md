Why it looks like that:
The reason you see the whole sentence repeat is because line 248 prints the text field, which in some event types contains the entire accumulated message so far, rather than just the new piece (the delta).

Because I added that "Thinking..." print on line 249 to give you visual feedback while the model is "working" (processing the next token), it creates that characteristic repeating list.
